# Multichannel Libri2Mix Speaker and Spatial Cue Recipe

> Last updated: 2026-09-21

This Linux recipe trains one BSRNN with both a speaker enrollment cue and a
target-direction cue. It reuses the four-channel waveforms and spatial cue
index generated by `examples/spatial/mc_librimix` and the mono enrollment
index generated by `examples/audio/librimix`.

Prepare those inputs first, then build this recipe's independent WeSep lists:

```bash
./run.sh --stage 1 --stop_stage 1 \
  --mc_librimix_root /path/to/WeSep-MC-LibriMix/wav16k/min \
  --audio_cue_root ../../audio/librimix/data/clean
```

Stage 1 creates `samples.jsonl`, `raw.list`, and `cues.yaml` for each split.
The cue file registers both `audio` and `spatial` as guaranteed target-speaker
cues. Training uses random enrollment utterances; development and test use
fixed enrollment utterances. Spatial cues always use `mix_key::spk_id`.

The official config requires both cues in every sample. The model also accepts
the optional `audio_aux_present` and `spatial_aux_present` masks emitted by the
collator, which can support separate missing-cue experiments.

## Stages

Stages 1–6 build the joint-cue lists, optionally create shards, train, average
checkpoints, infer, and score, respectively. Generate the multichannel data and
both prerequisite cue indexes before Stage 1. Data preparation and training
are the validated v0.1 path; inference and scoring remain under release-wide
validation.
